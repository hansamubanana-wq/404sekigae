# 司会者の素材

- 人型は Quaternius の Universal Base Characters Standard、動きは同作者の Universal Animation Library Standard を使用。両方の配布物に CC0 1.0 の記載がある。衣装のテクスチャ、口の動き、アニメーションの調整を加えた。 [人型モデル](https://quaternius.com/packs/universalbasecharacters)・[アニメーション](https://quaternius.com/packs/universalanimationlibrary.html)・[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- 英語の仮音声は PixVerse の MiniMax Speech 2.8 HD（Magnetic-voiced Male）。台詞の間を編集した。 [PixVerseの音声生成](https://github.com/PixVerseAI/skills)
- Noto Sans JP Black の字幕用サブセット。ライセンスは同梱の [OFL.txt](OFL.txt)。
