# 404 席替え

404 の席替えアプリ。three.js の 3D 演出で、2人ずつ席を発表します。

- 本番: https://404sekigae.vercel.app/ (main に入ると Vercel が自動で公開)
- iPad / iPhone / PC の Safari・Chrome 向け。ホーム画面に追加すると全画面のアプリとして使えます (PWA、オフライン対応)

## 使い方

| 操作 | 内容 |
| --- | --- |
| 席をタップ | その席を固定 (席替えで動かさない)。もう一度タップで解除 |
| 席替えスタート | 固定していない席をシャッフルして、2人ずつ発表 |
| スピーカー | 効果音・動画の音のオン/オフ (設定は記憶) |
| 保存 / 元に戻す / 印刷 | 席を端末に保存 / 出席番号順に戻す / 2D の座席表を印刷 |

URL のオプション: `?q=low` で軽い画質、`?slow=0.2` で演出をスロー再生 (確認用)。

## 発表の進み方

- **2人ずつ**発表する。1人で発表するのは**最後の1人**と**最前列中央の席** (動画がある) だけ。固定した席の関係で2人組が余るときだけ、最前列中央か最後の1人の直前に1人の回が入る
- 2人組の演出は 10 種類。山札方式で、全部ひととおり出るまで同じ演出は出ない (`pair.js`)

| 演出 | 内容 |
| --- | --- |
| 急降下 | カメラが1人目の席へ飛び込んで札が裏返り、2人目の席へ振って裏返り、引いて戻る |
| せり上がり | 2つの席の札が光の柱の中で高く浮かび、回りながら名前が出る |
| 隕石2連 | 名前カードが空から席めがけて落ち、衝撃で周りの机が跳ねる |
| カードシャッフル | 裏向きの2枚が奥行きを使って入れ替わり、同時にめくれて席へ飛ぶ |
| 粒子2本 | 光の粒が2人分の名前を同時に作り、カードになって席へ飛ぶ |
| 旋回 | カメラが教室のまわりを回り、通りすぎる席の札が裏返る |
| UFO | UFO が教室の上を飛び、席ごとにビームでカードを降ろす |
| 猫 | 3D の猫が教室の手前の床を走ってきて、席へカードを放り投げる |
| ロケット2機 | 教卓の前から打ち上がり、教室の上を回って席に突っ込む |
| スポットライト | 暗い教室をライトが探しまわり、2つの席でぴたっと止まる |

- 最後の1人は「最後の1人…」のあと、派手な演出 (急降下・ロケット・スポットライト・隕石・せり上がり) から選ぶ
- 途中にカットシーン (停電・教室ツアー・猫の行列・UFO の編隊) と「折り返し地点」「ラスト◯人…」が入る

## 最前列中央の席の動画演出

最前列 (教卓側の1列目) の**中央の席** (`0-3`) を発表するときだけ、完成動画 `media/the_front_row.mp4` を流します。

流れ: **前振り → 動画 → 締め → 既存の結果表示**

1. **前振り**: 上下に黒帯が入り、照明が落ちて、スポットライトとカメラが最前列中央の席 (まだ「?」の札) に寄る。札の金枠が鼓動に合わせて光り、字幕「最前列の中央は……」→ 席の位置に向かって丸くすぼまるように暗転
2. **動画**: 黒から浮かび上がるように再生。**操作 UI はなし、スキップ・一時停止・シークもできず、最後まで流れる**
3. **締め**: 名前の出た終了画面を少し見せてから、ゆっくり暗転 → 教室に丸く開いて戻り、字幕「― 最前列 中央 ―」→ カメラを元に戻す
4. 既存の結果表示 (名前カードが席へ着地)

- 動画: 20.000 秒 / 1280×720 / 24fps / H.264・AAC / 日本語字幕は焼き込み済み。受け取ったファイルをそのまま使用 (再エンコードなし。moov が先頭にあり、すぐ再生を始められる)
- 名前: その回の抽選結果 (`seats["0-3"]`) の名前を、**18.5 秒から**白紙の中心に文字で重ね、終了画面まで残す
  - 位置は、黒帯を除いた**実際の映像の矩形**に対して横 50.5% / 縦 47.5%。幅は映像の 40% 以内に収まるよう文字の大きさを自動調整 (一番長い名前で約 33%)
  - 表示は再生位置で決める (18.5 秒未満なら隠す)。判定は実際に画面に出たコマの時刻 (`requestVideoFrameCallback`) で行い、使えないブラウザでは `currentTime` を使う
- **順番**: 最前列中央の席の発表は、**最後から 10 番目に固定** (後ろに 9 人が残る)。終盤すぎると残りの顔ぶれで誰か分かってしまうため。ほかの席の順番はランダム
- **再生に失敗したとき** (読み込みエラー、10 秒たっても始まらない) は、動画を閉じてそのまま既存の結果表示に進む
- 音付きの自動再生が許されないブラウザでは消音で流す。iPad / iPhone 向けに、席替えスタートのボタンを押した瞬間に動画を一度再生可能な状態にしている
- 中央の席を固定している回は、発表がないので動画も流れない。中央の席だけは2人組にせず、必ず1人で発表する (動画のあとはカメラが席へ寄って札が裏返る)
- 動画の再生中は裏の 3D の描画を止める
- 設定は `frontrow.js` の `FRONT_ROW` (席、表示開始秒、位置、最大幅、最後から何番目か、終了画面を見せる時間など)

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` | 画面と UI |
| `students.js` | 名簿と教室の席の配置 |
| `app.js` | 席の状態・保存・席替えの進行 |
| `world.js` | 3D の舞台 (教室・名札・照明・ブルーム・粒子) |
| `models.js` | 3D の小道具 (猫・ロケット・目覚まし時計・風・紙吹雪) |
| `show.js` / `extras.js` | 発表の演出、カットシーン、進行表 |
| `frontrow.js` | 最前列中央の席の動画演出 |
| `sound.js` / `sounds/` | 効果音 (CC0 素材。出典は `sounds/CREDITS.txt`) |
| `media/the_front_row.mp4` | 最前列中央の席の動画 |
| `sw.js` / `manifest.webmanifest` / `icons/` | PWA (オフライン対応・ホーム画面のアイコン) |

ビルドは不要です。three.js は CDN から読み込みます。

## ローカルで動かす

ES モジュールと Service Worker を使うので、`file://` ではなく HTTP サーバーで開いてください。動画のシークには **Range リクエストに対応したサーバー**が必要です (`python3 -m http.server` は非対応で、シークすると先頭に戻ります)。

```bash
npx http-server -p 8080 -c-1
```

Service Worker は動画をキャッシュせず、Range リクエストをそのままネットに通します。
