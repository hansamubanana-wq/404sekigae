# 404 席替え

404 の席替えアプリ。three.js の 3D 演出で、2人ずつ席を発表します。

- 本番: https://404sekigae.vercel.app/ (main に入ると Vercel が自動で公開)
- iPad / iPhone / PC の Safari・Chrome 向け。ホーム画面に追加すると全画面のアプリとして使えます (PWA、オフライン対応)

## 使い方

| 操作 | 内容 |
| --- | --- |
| 席をタップ | 固定していない2席で、選んだ席とランダムな相手の人が移動して入れ替わる。最前列中央も同様に扱い、発表中のタップは無視する |
| 席を約0.6秒長押し | 席を固定する。固定した席は鍵マークを表示し、もう一度長押しすると解除する |
| 名札を別の席へドラッグ | 指で少し動かすとドラッグになり、離した先の席と入れ替わる。固定した席との入れ替えや発表中の操作はできない。変更は「保存」の対象になる |
| 席替えスタート | 固定していない席をシャッフルして、2人ずつ発表 |
| 保存 / 元に戻す / 印刷 | 席を端末に保存 / 出席番号順に戻す / 2D の座席表を印刷 |

URL のオプションは `?fps=30` で描画を毎秒30回に設定、`?q=low` で軽い画質、`?slow=0.2` で演出をスロー再生します。

3D の描画は既定で毎秒60回を目標にします。Canvas と3Dの中間面のピクセル比は端末の DPR に合わせて起動時に固定し、上限は通常2、`?q=low` は1です。iPad A16 の DPR 2 では、2360×1640 の全画面を表示パネルと同じ解像度で描きます。HDR の中間面は MSAA なしにし、ブルームの明部抽出とぼかしは幅・高さともに 1/4 以下で計算します。

起動時に壁のノイズを焼き込み、全員の名札・名前カード・粒子の文字マスクを GPU に転送します。机はインスタンス描画し、風やロケットなどの小道具は使い回します。

3D 描画: 今は WebGL2。WebGPU への移行はユーザー了承済み（2026-11-23）。使うのは iPad（A16）の Safari だけなので、WebGL2 へのフォールバックは不要（ごく少ない手間で今の形のまま残せるなら残してもよい）

## 発表の進み方

- **2人ずつ**発表する。固定した席の関係で2人組が余るときだけ、最後の組の直前に1人の回が入る
- **最後の3人**は特別: 「ラスト3人…」→ 残り3人の名前を並べて「この3人のうち、最前列の中央は……」→ 最前列中央の動画で誰かを明かす → 残りの2人は短い演出 (ポン + 弧) で決める
- 最前列中央の席を固定している回 (動画なし) は、最後の1人だけ「最後の1人…」のあと特別な演出で発表する
- 1回の発表は「**登場** (2人の名前カードを画面の真ん中に大きく出す) → 少し見せる → **移動** (それぞれの席へ)」。登場と移動はそれぞれ山札方式で、全部ひととおり出るまで同じものは出ない (`pair.js`)

| 登場 (13種類) | 内容 |
| --- | --- |
| ポン | 回りながら飛び出す |
| 粒子2本 | 光の粒が渦から集まって2人分の名前になる |
| カードシャッフル | 裏向きの2枚が奥行きを使って入れ替わり、同時にめくれる |
| 隕石 | 奥の空から火の玉になって落ちてくる |
| ワープ | 光のトンネルから飛び出してくる |
| 幕開け | 赤い幕が閉じて、ドラムロールのあと開く |
| ルーレット | 名前が高速で入れ替わり、1人ずつ止まる |
| サーチライト | ライトが探しまわり、下からせり上がる |
| ノイズ | 別人が映ったあと、調整して本人に |
| ジャイロリング | 斜めに回る3つの輪の中から登場。カメラが横に振れて奥行きを見せる |
| 水晶のせり上がり | 回転する水晶と一緒に下からせり上がる |
| 三重ゲート | 奥に並ぶ3つの光の輪をくぐって手前に飛び出す |
| 星座の展開 | 立体の星座が開き、その手前に名前が浮かび上がる |

| 移動 (16種類) | 内容 |
| --- | --- |
| 弧 | それぞれ弧を描いて席へ |
| カメラ追跡 | カードと一緒にカメラも席へ飛び込む (1人ずつ) |
| 空から落下 | いったん消えて、席めがけて火の玉で落ちてくる |
| ロケット | カードを乗せて打ち上がり、教室の上を回って席へ |
| UFO | 2枚まとめて吸い上げ、席ごとにビームで降ろす |
| 猫 | 猫がカードをくわえて、席まで走っていく |
| フェイント | 1枚が違う席に降りかけて「…ではなく！」 |
| バウンド | 机の上を跳ねて、本当の席へ |
| テレポート | 光の柱で消えて、席の上に現れる |
| 強風 | 吹き飛ばされて、ひらひら席へ舞い降りる |
| せり上がり | 席の光の柱に吸い込まれ、札が浮かびながら名前が出る |
| スポットライト | 暗い教室でライトが2つの席に止まり、そこへカードが飛ぶ |
| 光のレール | それぞれの席へ伸びる曲線の光をたどって着地する |
| リング・スラローム | 斜めに並ぶ3つの輪を縫い、左右の席へ分かれる |
| 二重らせん | 2枚がらせんを描いて回り、光の粒を残して着地する |
| 天井クレーン | 水晶がカードを持ち上げ、席の真上まで運んで降ろす |

- 最後の1人は「最後の1人…」のあと、登場はカウントダウン・幕開け・ワープ・サーチライト、移動はカメラ追跡・ロケット・空から落下・スポットライトから選ぶ
- 発表回数に応じて「折り返し地点」「ラスト◯人…」を表示する。抽選した席はそのまま順に発表する
- 全員決定後は `finale` を流しながらカメラが約12秒かけて教室を一周し、その後は教室全体を見渡せる視点で止まる

## BGM

Gemini で生成した歌のない3曲を、ステレオの AAC（M4A）に加工して使用します。曲の読み込みは席替えを始めてから行い、切り替えは1.25秒のクロスフェードです。

| 曲 | 鳴る場面 |
| --- | --- |
| `main` | 「席替えスタート」から発表中 |
| `tension` | 「ラスト3人…」など終盤のカウントから。最前列中央の動画中は BGM の音量を絞り、動画のあとの残りの発表ではこの曲を流す |
| `finale` | 「全員決定！」から、通常の座席表に戻るまで。戻るとフェードアウト |

## 最前列中央の席の動画演出

最前列 (教卓側の1列目) の**中央の席** (`0-3`) を発表するときだけ、完成動画 `media/the_front_row.mp4` を流します。

流れ: **前振り → 動画 → 締め → 既存の結果表示**

1. **前振り**: 上下に黒帯が入り、照明が落ちて、スポットライトとカメラが最前列中央の席 (まだ「?」の札) に寄る。札の金枠が鼓動に合わせて光り、字幕「最前列の中央は……」→ 席の位置に向かって丸くすぼまるように暗転
2. **動画**: 黒から浮かび上がるように再生。**操作 UI はなし、スキップ・一時停止・シークもできず、最後まで流れる**
3. **締め**: 名前の出た終了画面を少し見せてから、ゆっくり暗転 → 教室に丸く開いて戻り、字幕「― 最前列 中央 ―」→ カメラを元に戻す
4. 既存の結果表示 (名前カードが席へ着地)

- 動画: 放課後の夕方の教室 (実際の 404 教室に寄せた絵) を、カットなしの1回撮りで後ろから最前列の中央の机へ進み、机の上の二つ折りの紙が開いたところを上から映す。10.54 秒 / 1280×720 / 24fps / H.264・AAC / 台詞・字幕なし
  - 作り方: 最初のコマの静止画を画像生成で作り、PixVerse の v6 (720p・9秒、画像から動画) で生成。最後のコマを 1.5 秒止めて名前を重ねやすくし、moov を先頭に置いて再エンコード
  - 差し替えたら `frontrow.js` の `src` の `?v=` を上げる (古い動画がキャッシュに残らないように)
- 名前: その回の抽選結果 (`seats["0-3"]`) の名前を、**9.1 秒から**机の上の白紙の中心に文字で重ね、終了画面まで残す
  - 位置は、黒帯を除いた**実際の映像の矩形**に対して横 50% / 縦 52.5%。幅は映像の 36% 以内に収まるよう文字の大きさを自動調整
  - 表示は再生位置で決める (9.1 秒未満なら隠す)。判定は実際に画面に出たコマの時刻 (`requestVideoFrameCallback`) で行い、使えないブラウザでは `currentTime` を使う
- **順番**: 最前列中央の席は必ず**最後の3人**の中に入る。残り3人の名前を見せてから動画で明かすので、3人のうち誰が最前列の中央かが最後の見どころになる。ほかの席の順番はランダム
- **再生に失敗したとき** (読み込みエラー、10 秒たっても始まらない) は、動画を閉じてそのまま既存の結果表示に進む
- 効果音・BGM・動画は音付き。iPad / iPhone 向けに、席替えスタートを押した瞬間に動画を再生可能な状態にしている
- 中央の席を固定している回は、発表がないので動画も流れない。中央の席だけは2人組にせず、必ず1人で発表する (動画のあとは名前カードを出し、カメラと一緒に席へ飛び込む)
- 動画の再生中は裏の 3D の描画を止める
- 設定は `frontrow.js` の `FRONT_ROW` (席、表示開始秒、位置、最大幅、最後から何番目か、終了画面を見せる時間など)

## ローカルで動かす

ES モジュールと Service Worker を使うので、`file://` ではなく HTTP サーバーで開いてください。動画のシークには **Range リクエストに対応したサーバー**が必要です (`python3 -m http.server` は非対応で、シークすると先頭に戻ります)。

```bash
npx http-server -p 8090 -c-1
```

Service Worker は動画をキャッシュせず、Range リクエストをそのままネットに通します。
BGM は席替え開始後に取得し、通常のファイルと同じようにキャッシュします。
